# JDBC driver

Spark needs the PostgreSQL JDBC driver to read from and write to the database.

Download `postgresql-42.7.4.jar` from
[Maven Central](https://repo1.maven.org/maven2/org/postgresql/postgresql/42.7.4/postgresql-42.7.4.jar)
and save it in this folder:

```
jars/postgresql-42.7.4.jar
```
